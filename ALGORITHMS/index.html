Σ Algorithms Cheat-Sheet

1. Logic Functions & Minimization
  • Boolean Functions: 2^(2^n) total functions; 2^(2^(n-1)) self-dual functions.
  • Absorption & Consensus: x + xy = x, x + x'y = x + y, xy + x'z + yz = xy + x'z.
  • Universal Gates: {NAND} and {NOR} are functionally complete; XOR needs 4 NANDs.
2. Combinational Circuits
  • Asymptotic Hierarchy: O(1) < O(log log n) < O(log n) < O(n^ε) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
  • Master Theorem: For T(n) = aT(n/b) + f(n) (a≥1, b>1), compare f(n) with n^(log_b a): (1) smaller → Θ(n^log_b a); (2) equal · log^k n → Θ(n^log_b a · log^(k+1) n); (3) larger + regularity → Θ(f(n)).
  • Sorting Complexities: Merge Sort Θ(n log n) (stable, O(n) space); Quicksort Θ(n log n) avg / Θ(n²) worst; Insertion Sort Θ(n) best / Θ(n²) worst (stable); Heap Sort Θ(n log n) in-place.
  • Minimum Spanning Tree (MST): Kruskal O(E log V); Prim O(E log V) (binary heap). Cut property: lightest edge across any cut is in some MST. Unique weights ⇒ Unique MST.
  • Shortest Paths: Unweighted (BFS) O(V+E); DAG O(V+E); Dijkstra (non-neg) O((V+E) log V); Bellman-Ford O(VE); Floyd-Warshall (all-pairs) O(V³).
  • Heaps & Hashing: Build-Heap Θ(n); Extract/Insert O(log n); Leaves = ⌈n/2⌉. Chaining avg probe = 1 + α (α = n/m).
  • P, NP & Reductions: If A ≤_p B and B ∈ P ⇒ A ∈ P. If A is NP-hard and A ≤_p B ⇒ B is NP-hard.
