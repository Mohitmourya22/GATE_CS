Σ Digital Logic Cheat-Sheet

1. Logic Functions & Minimization
  • Boolean Functions: 2^(2^n) total functions; 2^(2^(n-1)) self-dual functions.
  • Absorption & Consensus: x + xy = x, x + x'y = x + y, xy + x'z + yz = xy + x'z.
  • Universal Gates: {NAND} and {NOR} are functionally complete; XOR needs 4 NANDs.
2. Combinational Circuits
  • MUX Implementation: Any n-variable function needs at most one 2^(n-1):1 MUX + 1 inverter.
  • Decoder Expansion: m:2^m from k:2^k decoders needs ⌈2^m/2^k⌉ + ... tree levels.
  • CLA Adder: Fan-in ≤ 2 depth is Θ(log n); 4-bit CLA uses 10 AND + 4 OR gates.
3. Sequential Circuits
  • Mod-N Counter: Minimum flip-flops = ⌈log₂(N)⌉; Johnson counter (n-bit) has 2n states; Ring has n.
  • Max Clock Frequency: f_max = 1 / (T_FF + T_comb + T_setup).
  • NAND SR Latch: S=0, R=0 forces invalid Q = Q' = 1.
4. Number Systems
  • n-bit 2's Complement: Range [-2^(n-1), 2^(n-1) - 1], unique 0; Sign-Magnitude & 1's comp have +0, -0.
  • IEEE 754 Single (32-bit): 1 Sign + 8 Exp (bias 127) + 23 Mantissa: (-1)^s × 1.M × 2^(E-127).
  • Booth's Algorithm: Worst case is alternating 1010...10; Bit-pair recoding uses -2x_{i+1} + x_i + x_{i-1}.
