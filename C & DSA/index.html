Σ Revision Cheat-Sheet

1. C Programming & Scoping
  • Static Scoping: resolves non-local names by lexical nesting in source code. Dynamic Scoping: resolves by runtime call stack.
  • Precedence: () [] -> . (highest, L→R) > unary ++ -- * & (R→L) > arithmetic > relational > =.
  • Static locals retain value across calls; auto/register re-initialize on each call.
2. Arrays & Matrices
  • Row-Major A[i][j]: Base + ((i - lb1) * cols + (j - lb2)) * size.
  • Lower Triangular (1-idx): i(i - 1)/2 + (j - 1).
  • Build-Heap: bottom-up Floyd's algorithm takes O(n).
3. Stacks, Queues & Linked Lists
  • Circular Queue: Empty: REAR == FRONT; Full: (REAR + 1) % n == FRONT.
  • Circular LL Queue: single pointer p at rear gives O(1) enqueue & dequeue.
  • Linked List: no O(1) random access ⇒ binary search is O(n).
4. Trees, BST & Heaps
  • Binary Tree: n₀ = n₂ + 1. Height h (edges): min nodes = h + 1, max = 2^(h+1) - 1.
  • Complete k-ary Tree: leaves L = I(k - 1) + 1.
  • Distinct BSTs on n keys: Catalan C(2n, n) / (n + 1).
  • BST Inorder: always sorted ascending. Unique Tree: Inorder + (Preorder or Postorder).
5. Graphs & Hashing
  • DFS / BFS: Θ(V + E) with adjacency list, Θ(V²) with adjacency matrix.
  • DFS Forest: n vertices, k tree edges ⇒ n - k connected components.
  • Hashing: Load factor α = n / m. Chaining makes deletion easier than open addressing.
