# GATE CS & IT — Complete PYQ Hub

A browser-based practice platform for GATE Computer Science and Information Technology preparation. It brings previous-year questions, topic-wise practice, timed quizzes, solutions, and progress tracking into one place.

## Live website

- **[Complete PYQ Hub](https://mohitmourya22.github.io/GATE_CS/all/)** — all 12 subjects and questions from 2008–2026
- **[Programming & Data Structures](https://mohitmourya22.github.io/GATE_CS/C%20%26%20DSA/)** — topic-wise PYQs with solutions, visuals, and revision notes
- **[Digital Logic](https://mohitmourya22.github.io/GATE_CS/DELD/)** — logic design and number-system practice with PDF solutions and visuals

## Subjects covered

- Database Management System
- Operating System
- Computer Networks
- Computer Organization & Architecture
- Programming & Data Structures
- Algorithms
- Compiler Design
- Theory of Computation
- Digital Logic
- Discrete Mathematics
- Engineering Mathematics
- General Aptitude

## Features

- Practice questions by subject, topic, year, difficulty, and question type
- Timed quizzes and full-length mock practice
- Instant answers and detailed solution views
- PDF solution references and visual explanations where available
- Mark questions for review and revisit them later
- Topic-wise accuracy and progress tracking
- Revision cheat sheets for focused preparation
- Progress saved locally in the browser

## Usage

Open the [live website](https://mohitmourya22.github.io/GATE_CS/all/) in a modern browser. No installation or build step is required. Select a subject or topic, choose a practice or quiz mode, and begin solving.

## Local development

Clone the repository and open `all/index.html` directly in a browser:

```bash
git clone https://github.com/Mohitmourya22/GATE_CS.git
cd GATE_CS
```

The project is implemented as standalone HTML pages and uses browser-local storage for progress.
