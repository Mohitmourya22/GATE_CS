# GATE CS & IT — Complete PYQ Hub

A browser-based practice platform for GATE Computer Science and Information Technology preparation. The repository contains previous-year questions, topic-wise practice, timed quizzes, solutions, visual explanations, and local progress tracking.

## Live pages

- **[Complete PYQ Hub](https://mohitmourya22.github.io/GATE_CS/all/)** — all 12 subjects with PYQs from 2008–2026
- **[Algorithms](https://mohitmourya22.github.io/GATE_CS/ALGORITHMS/)** — 264 Algorithms PYQs with focused practice tools
- **[Programming & Data Structures](https://mohitmourya22.github.io/GATE_CS/C%20%26%20DSA/)** — PYQs from 1987–2026 with solutions, visuals, and revision notes
- **[Digital Logic](https://mohitmourya22.github.io/GATE_CS/DELD/)** — 216 PYQs with number-system and logic-design practice
- **[Spatial PYQ Lab](https://mohitmourya22.github.io/GATE_CS/Solutions/Solution.html)** — interactive practice for stacks, queues, arrays, linked lists, pointers, and strings

## Features

- Practice questions by subject, topic, year, difficulty, and question type
- Timed quizzes and full-length mock practice
- Instant answers and detailed solution views
- PDF solution references and visual explanations where available
- Mark questions for review and revisit them later
- Topic-wise accuracy and progress tracking
- Revision cheat sheets for focused preparation
- Progress saved locally in the browser

## Usage

Open the [Complete PYQ Hub](https://mohitmourya22.github.io/GATE_CS/all/) or any subject page in a modern browser. No installation or build step is required. Select a subject or topic, choose a practice or quiz mode, and begin solving.

## Local development

Clone the repository and open any page directly in a browser:

```bash
git clone https://github.com/Mohitmourya22/GATE_CS.git
cd GATE_CS
```

The project is implemented as standalone HTML pages and uses browser-local storage for progress.
